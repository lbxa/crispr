# Crispr chat workbench (prototype)

Not a Bun workspace: it has its own package.json and is intentionally outside `apps/*` and `libs/*`, so it is not part of `turbo` tasks or `bun.lock`. The built page is served by the website at `/chat` (`apps/web/app/chat`, `apps/web/public/workbench/index.html`). After changing `web/template.html` or `web/engine.ts`, run `npm run build:web` here and copy `web/index.html` to `apps/web/public/workbench/index.html`.

Simulated genomes only. Not medical advice. Off-target risk is NOT assessed anywhere in this code.

## What is here
- `web/` the UI. `template.html` is the source, `engine.ts` bundles the real retrieval code for the browser. `index.html` is generated by `npm run build:web` and is not stored here (the built copy lives in `apps/web/public/workbench/`).
- `lib/` knowledge graph, entity linker, scoring, metrics (guide geometry, edit planner), retrieval, paper search/cache.
- `agent/` AI SDK v7 tool loop, streaming handler, grounding check, demo model.
- `app/api/` thin route wrappers (`/api/chat`, `/api/state`).
- `scripts/` tests, benchmark, local server.

## Run
    npm install        # or bun install
    npm test            # 12 tests
    npm run typecheck
    npm run build:web   # rebuilds web/index.html (needs python3)
    npm run dev         # http://localhost:3000  (mic works on localhost)

Set `AI_GATEWAY_API_KEY` to use a real model (default `anthropic/claude-sonnet-5.5`, override with `CRISPR_MODEL`). Without it a demo model restates retrieved facts.

## Not verified
Real LLM, live Europe PMC, Ensembl sequence, real microphone, and the accuracy of the illustrative seed data (genes, variants, coordinates, symptoms).
